# 情商超人 MVP

一个像背单词一样的快问快答式沟通能力训练器。

## 当前玩法

- 识别感受：30 道情境，每局随机 8 题；
- 弦外之音：24 道对话，每局随机 8 题；
- 每题限时 20 秒，答题后即时给出关键词、参考表达和简短辨析；
- 五棵不同果树承载 38 个情绪与关系需要概念；
- 答题记录、果实点亮与成熟阶段保存在浏览器 `localStorage`；
- 每个浏览器拥有独立匿名 ID，并保存最近 20 局训练历史；
- 果园支持二次确认后清除本机测试数据；
- 成功、失败和通关分别使用不同的 Web Audio 提示音；
- 新果实出现与已有果实成长拥有不同的弹出、回弹、闪光动画和提示音；
- 关卡结束后直接进入果园，并在果园上方完成本局结算。

## 本地运行

```bash
python3 -m http.server 4173
```

访问 `http://127.0.0.1:4173/`。

## 文件

- `index.html`：主页、关卡、果园和结算结构；
- `styles.css`：桌面和移动端视觉；
- `data.js`：概念树、定义和两套题库；
- `app.js`：游戏状态、判分、熟练度、持久化和页面流程。

## 当前边界

这是无需 API 密钥的产品效果 Demo，开放回答采用本地关键词规则判定。正式产品若接入大模型，应通过服务端执行语义评分，并使用黄金回答集做回归测试，不能把密钥放进前端。

## 未来账号迁移

本地数据使用固定存储键 `eq-superman-mvp-v1`，数据内部带有 `schemaVersion`、`anonymousId`、创建/更新时间和同步时间。正常网页版本更新不会删除该键。

未来登录后可以调用 `window.EQSupermanStorage.exportForAccount()` 读取完整本地进度，上传并合并到账号；服务端确认成功后调用 `markSynced()` 标记同步，不应在确认前删除本地副本。现有无版本数据会在读取时自动迁移到版本 2。
