# 情绪捕手

一个 20 秒情绪命名小游戏：NPC「零」讲述一段短暂的内心片段，玩家用一个感受词作答。答错或超时会立即给出更准确的词与辨析。

## 本地运行

这是一个零依赖的静态网页。直接打开 `index.html`，或在项目目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 首版范围

- 24 道内置题目，每局随机抽取 10 道
- 20 秒倒计时、超时判定和 3 秒自动下一题
- 常用近义词与“相近但未通过”的区分
- 连胜、速度加分、局后薄弱类型提示

## 关于“AI NPC”

首版为了能免费、稳定且不泄露密钥地上线，采用本地题库和情绪词判定规则。NPC 的人物语气、题目与反馈均已设计为 AI 角色体验。

若要支持玩家输入任意长句、由大模型进行语义裁判，需要增加一个服务端接口并由部署者配置 API 密钥；不要把此类密钥写进浏览器端文件。
